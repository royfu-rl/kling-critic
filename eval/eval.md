tag 暂时不会全部进入机评，取舍主要看：根据历史统计的人评一致性，判断该 tag 是否过于主观。以及与其它 tag 边界是否清晰。

**优先执行高人评一致性 tag**
- **客观标签**：有明确物理或事实判据（结构崩坏、纹理抖动、指令遗漏、音画不同步），标注员人评应高度一致（方差小），机评更容易替代人评。
- **主观标签**：与审美、叙事、情绪相关，人评一致性天然较低：
  - **画面美学**：材质质感、空间层次与构图布局、色彩搭配与光影表现、环境布景、主体美感全部依赖标注员审美，方差过大。
  - **动态美学与视听叙事**：叙事节奏、运镜节奏、剪辑节奏、创意性等纯主观视听项留在体系内，依赖成对偏好与多人聚合，不追求逐条硬判。

**边界划分**

让同一个现象稳定落到唯一 tag

按是否改动标签结构，治理动作分两类：

- **改体系**：增减标签本身，包括合并、重命名、移出、删除。
- **划范围**：不动标签，只划定适用范围，包括需硬隔离、需锚定、需互斥、需禁用、需降级。

| 治理动作 | 解决的边界问题 | 实例 |
| :--- | :--- | :--- |
| 合并 | 程度副词当标签用，阈值随标注员漂移 | 明显崩坏与轻微崩坏合并为崩坏，程度改由严重度字段承载 |
| 重命名 | 陈述式标签描述属性而非缺陷，标注员无法判断打标方向 | 动态时序一致性改为动态时序不一致，动作文本响应改为动作未响应 |
| 移出 | 同一缺陷在两个维度各留一份 | 动态美学下的全部音频标签（音频基础质量差、音画不同步、音画不匹配、声音融合与切换等）移出，统一归音频评测维度 |
| 删除 | 缺少客观锚点，或与既有标签高度重叠 | 镜头连贯性与指令遵循的镜头时序问题重叠，删除 |
| 需硬隔离 | 两个标签的表象经常同时出现，标注员双打 | 细节纹理抖动只判帧间位移与闪烁，纹理虚假只判单帧渲染错误 |
| 需锚定 | 灰色案例没有归口判据 | 速度违反物理规律归动态质量的速度异常，速度符合物理但违反 prompt 归指令遵循的播放速度不符 |
| 需互斥 | 长程问题与微观问题同时触发 | 动态时序不一致管 3 秒以上的长程逻辑，卡顿掉帧感管帧间插值平滑度 |
| 需禁用 | 缺陷来自输入条件而非模型 | prompt 本身叙事碎片化时停用叙事不连贯，不因剧本混乱惩罚模型 |
| 需降级 | 兜底标签抢占具体标签 | 复杂文本理解错误仅在无法拆解为具体标签时启用 |

处理顺序固定：先合并归一，再补各档锚点示例，最后才纳入训练集。

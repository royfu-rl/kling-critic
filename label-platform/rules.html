Annotation Protocol

双人盲标 · 复核 · 评测员终审

一条视频要进训练集，必须先在这套流程里拿到一个没有争议的结论。规则分三块：谁来标、怎么定终态、什么情况不交付。

一 · 角色与账号

标注员 A盲标槽位 1annotator_1
标注员 B盲标槽位 2annotator_2
复核员两人分歧时仲裁，可多人reviewer_3
评测员终审，共享一个槽位admin

槽位由服务端在登录后分配，同一条视频的两个标注槽位不会落到同一个人。

账号隔离。两名标注员互相看不到对方的结论、证据框和备注，也看不到当前视频的终态—— 终态是从别人的判断推出来的，露出来盲标就失效了。复核员能看到两名标注员；评测员能看到所有人。

二 · 视频级终态

按优先级往下走，命中即停：

  1. 评测员标了 → 用评测员的结论
  2. 两名标注员一致 → 用该结论
  3. 不一致 → 用复核员的结论；多名复核员按 sha256 稳定挑一个，避免每次回放结果不同
  4. 以上都拿不到 → 不交付（分歧未复核 / 标注未完成）

三 · 证据级终态

每条人工框单独定，优先级同上：评测员 > 复核员 > 画框的标注员。

情形结果
评测员显式标了 ✅❎⭐️，或自己补了框按评测员
复核员显式标了按复核员
视频级终审判「无」没被单独标过的框，随视频一并不采纳
标注员画了框，无人改判采纳（画框本身就是认定）
⭐️（轻微）采纳，按轻微处理

只有采纳的证据进交付件；不采纳的留在报告里记 不采纳·<谁定的>，不进训练数据。

一条容易踩的边界。视频级判「有」、却没有任何一条被采纳的证据 → 不交付。 这种样本按 verdict=无异常 交出去就是错标签，宁可丢掉。

四 · 质检指标

指标口径看什么
人评一致性 两名标注员在视频级结论上的一致率，配 2×2 混淆矩阵 一致率低说明标注规范本身有歧义，要回头改规则而不是压标注员
抽检标注准召 以评测员终审为真值，统计标注员提交证据的准确率 / 召回率 / F1 准确率低 = 乱framing；召回率低 = 漏标，两者要分开治

两项都按批次、按 L3 标签切片看——总体达标但某个垂类塌陷是常态。
